# Porter Mobile

The iOS-first Porter mobile app, built with React Native, Expo, TypeScript, and Expo Router.

## Prerequisites

- Node.js 22.13 or newer
- npm
- Xcode with the iOS Simulator

## Start the app

From `apps/mobile`:

```bash
npm install
npx expo start
```

Press `i` in the Expo terminal to open the app in the iOS Simulator.

## Quality checks

```bash
npm run lint
```
